# Student Management System

## Project Description
A Java console application used to manage student records.

## Features
- Add new students
- Add marks for students
- Display all students
- Search student by ID
- Show student with highest average mark
- Calculate average and grade

## Classes Used
1. Student
2. StudentManagementApp

## How to Run
1. Open the project in Eclipse IDE.
2. Run StudentManagementApp.java.
3. Use the menu options to manage students.
